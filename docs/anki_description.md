Featuring vocabulary for all stages of Japanese learning. The JLPT (Japanese Language Proficiency Tests) are certification of fluency for non-native speakers, and the official language test of Japan. It consists of 5 levels, with <b>N5</b> as a beginner friendly exam for Japanese Language, while <b>N1</b> is the hardest.

The deck is organised in order of advancing grade, making studying a particular grade very easy straight after downloading, no extra steps necessary! Each outer deck contains all the cards of the previous grade, plus those of the current grade. So by default, studying the N3 deck also includes all the vocabulary for N4 and N5 as well. The deck is split into subdecks as follows:
<ul><li> JLPT-N1 (3056 notes) </li><ul><li> JLPT-N2 (1724 notes)</li><ul><li> JLPT-N3 (1591 notes)</li><ul><li> JLPT-N4 (613 notes)</li><ul><li> JLPT-N5 (625 cards)</li></ul></ul></ul></ul></ul>

The flashcards are styled by default to include <b>clickable kanji</b>. Such kanji can be clicked to display the furigana (pronunciation) of the kanji.

The programming script and readme for generating this deck is available at <a href="https://github.com/coolmule0/JLPT-N5-N1-Japanese-Vocabulary-Anki" rel="nofollow">Github</a> or <a href="https://codeberg.org/coolmule0/JLPT-N5-N1-Japanese-Vocabulary-Anki">Codeberg</a>. Check it out if you have a programming background, you want to make your own adjustments to the deck programmatically, or you just want to see how the sausage is made.

Vocabulary is collected from the <a href="http://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project" rel="nofollow">JMdict</a> dictionary file.
